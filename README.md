# DS_project

Analysis of Ski Resort Prices in the U.S. and Europe -- Fall 2025 Final Project

Data Organizaiton:
  - Raw_Data: contains files downloaded from open access sources used in code
  - Cleaned_Data: output datasets resulting from cleaning and manipulating of Raw_Data files. Cleaned_Data files were used in all analyses
  - ipynb_code:
       - code_for_visuals: IPYNB with code used for descriptive, explanatory, and predictive analsyis using World Resorts Data
    - contains code for and resulting images of resort location maps and price analysis
